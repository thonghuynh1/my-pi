### Implementation map

**File**: `conductors/my-customize-conductor/my-customize-conductor.ts`

**Two group creation paths need wiring:**

1. **`createGroup()` (rollover path, line ~191–213):**
   - Currently builds a digest via `chunkedCompaction.composeDigest()` (BM25-derived structured digest + MCP retrieval index).
   - Change: Replace or augment with `buildSemanticDigest(candidates, meta)` call.
   - The conductor has `ViewBlock[]` with full `text`, `toolName`, `isError`, `kind`, `turn`, `tokens`, `id` — all fields needed by the extractors.
   - Compute `DigestMeta` from the candidates: `foldCode` (generated by store, not available here — use empty string or placeholder; the store's `createGroup` will assign the real fold code), `blockCount`, `turnRange` (min/max turn from candidates), `tokens` (sum).

2. **`createDefaultGroup()` (pressure/emergency path, line ~293–295):**
   - Currently returns `{ kind: "group", ids }` with NO digest (undefined → engine fallback).
   - Change: Compute `buildSemanticDigest(candidates, meta)` and pass as `digest`.

**Key seam detail — fold code:**
- The `{#code FOLDED}` tag uses the Group's `id` which is assigned by `store.createGroup()` AFTER the conductor returns its command.
- The conductor does NOT know the fold code at command time.
- **Resolution**: The conductor supplies only the digest body. `AccordionStore.groupSummary()` strips any leading supplied tag and prefixes the authoritative tag derived from the assigned group ID.
- `GroupCommand.lifecycle` keeps transient pressure groups distinct from stable rollover groups without parsing digest text.

The implementer must verify this seam and choose the cleanest approach.

**ViewBlock fields available to conductor:**
```typescript
id, kind, turn, order, tokens, foldedTokens, toolName, callId,
isError, proactivelyCompressed, held, folded, protected, grouped,
text?, preview?, messageKey?
```

All fields needed by `ExtractableBlock` (`kind`, `toolName`, `isError`, `text`) plus `id` (for MCP recall codes) are present on `ViewBlock`.
